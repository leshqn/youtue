# Leshan's Omniverse — brand assets

| File | Use |
|---|---|
| `logo.png` (1024×1024) | YouTube profile picture, socials |
| `logo.svg` | Scalable master — watermarks, print, any size |
| `banner.png` (2560×1440) | YouTube channel banner (art) |
| `banner.svg` | Scalable master |
| `gen_logo.py`, `gen_banner.py` | Regenerate the SVGs if you want to tweak |

## Concept
A Maasai beadwork ring and crossed warrior spears forming a shield that opens
onto a galaxy — heritage on the outside, an infinite universe within.

## Banner safe area
The canvas is 2560×1440, but phones only show the centred **1546×423** strip —
all text and the emblem are kept inside it, so nothing important is ever cropped.

Regenerate with `python brand/gen_logo.py` / `python brand/gen_banner.py`
(then rasterise the SVG to PNG with any converter).
